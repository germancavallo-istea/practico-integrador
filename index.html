Trabajo Practico

German Victor Cavallo

Esta es una página web simple ejecutándose en un contenedor.

Objetivo del TP.

  • Reforzar el manejo del control de versiones con Git y plataformas remotas (GitHub, GitLab o Bitbucket).
  • Comprender el ciclo de vida completo de un contenedor en Docker.
  • Integrar una aplicación simple dentro de un entorno contenerizado reproducible.
  • Documentar el proceso técnico y los comandos empleados en un archivo README.md profesional.

Consigna General

Deberás desarrollar una mini aplicación funcional (puede ser una página HTML, un servidor Node.js o una app Python sencilla), alojarla en un repositorio remoto y ejecutar su despliegue utilizando Docker.

El trabajo debe demostrar tu capacidad para:

  • • Gestionar versiones de código con Git.
  • Descargar e implementar imágenes base desde Docker Hub.
  • Construir y ejecutar contenedores personalizados.
  • Documentar todo el proceso de manera clara y técnica.

Entrega final

Debés compartir:

  • El enlace al repositorio remoto (GitHub, GitLab o Bitbucket).
  • El archivo README.md con la documentación del proceso.
  • (Opcional) Capturas o video breve mostrando la aplicación ejecutándose dentro del contenedor.
